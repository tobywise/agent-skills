# Slide deck

Create a navigable HTML slide deck (with a sidebar for navigation) that explains
the topic the user named, or what you have been discussing. It should be
professional looking and visually appealing, using custom fonts from Google
Fonts and a consistent colour scheme.

The slide deck should explain any technical concepts in a clear and accessible
way, using diagrams and examples where appropriate. DAGs should be used to
illustrate workflows, dependencies, and component interactions.

Try to use concrete examples from the codebase to illustrate concepts where
possible, and include links to relevant files or sections of the codebase for
further reading.
